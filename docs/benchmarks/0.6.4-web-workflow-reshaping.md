# 0.6.4 Web Workflow Reshaping Benchmarks

Measured on the local API-source SQLite store on 2026-07-31. The store contains
22 dates (`2026-07-06` through `2026-07-27`), 838 sensors on the latest date,
88 active models, and 84 adjacent drift pairs. HTTP timings are medians of five
local warm requests except where noted; they are not load-test results.

## Startup and Payload Boundary

| Read | 0.6.3 payload | 0.6.4 payload | Median time | Result |
|---|---:|---:|---:|---|
| Browser bootstrap | 335,955 bytes (`/api/artifacts`) | 7,220 bytes (`/api/context`) | 59.93 ms | 97.85% smaller |
| Equipment tree | 578,070 bytes | 578,070 bytes | 103.02 ms | unchanged contract |
| Default Review | 1,393,235 bytes | 746,449 bytes | 174.69 ms | 46.42% smaller |
| Initial API payload total, excluding tiny health response | 2,307,260 bytes | 1,331,739 bytes | n/a | 42.28% smaller |

Startup makes four API requests: health, compact context, equipment tree, and the
active Review. It makes no `/api/cluster-explorer` request. Review now receives
cluster membership counts rather than PCA assignment rows; the full projection is
loaded only after Cluster is activated.

The context response is 46.5 times smaller than the compatibility inventory. This
directly reduces transferred and parsed JSON. Browser heap was not separately
instrumented, so this is reported as reduced network/parse pressure rather than a
claimed heap-size measurement.

## Active Views

| Read | Scope | Rows / coverage | Payload | Median time |
|---|---|---:|---:|---:|
| Cluster explorer | all | 838 points | 648,825 bytes | 41.76 ms |
| Cluster explorer | asset tree `3757` | 4 points | 9,287 bytes | 30.19 ms |
| Drift overview | all | 4 feature spaces / 84 pairs | 55,594 bytes | 1.191 s |
| Drift overview | asset tree `3757` | 4 feature spaces / 84 pairs | 43,439 bytes | 1.306 s |

The scoped Cluster response is 98.57% smaller than the all-sensor response because
membership is applied in SQLite before serialization. The Drift response delivers
all four active feature spaces in roughly the same payload as the old single-space
22-date window (54,564 bytes in `0.6.3`). Pair metrics use stored summaries for the
all-scope case and query scoped assignments only when a scope requires
recalculation.

## JavaScript and Process Memory

| Figure | 0.6.3 | 0.6.4 | Change |
|---|---:|---:|---:|
| App-owned JavaScript | 57,594 bytes | 45,313 bytes across 3 modules | 21.32% smaller |
| Total browser JavaScript including unchanged chart engine | 78,546 bytes | 66,265 bytes | 15.64% smaller |

The final local service process used:

| State | Working set | Private bytes |
|---|---:|---:|
| Idle after startup | 61,730,816 | 48,537,600 |
| After default Review startup | 68,976,640 | 55,881,728 |
| After all-sensor Cluster | 69,140,480 | 55,881,728 |
| After all-feature Drift | 69,619,712 | 56,307,712 |

The Drift summary path initially loaded assignment rows unnecessarily; avoiding
that work keeps the final post-Drift working set at 66.39 MiB.

## Disk Boundary

`observations.sqlite` remained exactly 244,944,896 bytes. The processed inventory
remained 833 files and 332,747,442 bytes, and `git status` reported no processed-data
changes. Sprint `0.6.4` adds only small source/static modules and creates no new
operational artifacts.
